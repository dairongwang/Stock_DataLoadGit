# Your customer account

## Creating an account and signing in

*Create account* asks for e-mail and password; a **verification code** is
e-mailed and must be entered before the first sign-in. Alternatively
*Continue with Google / Apple / Facebook*. Bought tokens as a guest before?
Enter one of your **order references** when registering to link those keys
and tokens to the new account.

Sign in with e-mail + password or a connected provider; if you enabled a
second factor you are asked for it next. *Forgot your password?* sends a
reset link.

## The account page

| Block | What you can do |
|-------|-----------------|
| Stats | tokens available, requests served, tokens used, rows delivered |
| API keys | **+ New key** (empty, top it up later), **Rotate** (new secret, same balance), **Revoke**, rename |
| Orders | every purchase with its receipt |
| Recent requests | what your keys fetched and what it cost |
| Change password | (accounts created through a provider set a password via *Forgot your password*) |
