Authentication

Send your key (sdl_…) with every request - one of:

HeaderAuthorization: Bearer <key> (preferred)
HeaderX-API-Key: <key>
Query?api_key=<key> (ends up in logs - avoid)

No key yet? Buy a token pack - the receipt shows the key once. Lost it? Rotate it on your account page or the receipt; the balance stays.

What costs tokens

  • {{ settings.tokens_per_query }} token{{ 's' if settings.tokens_per_query != 1 }} per ticker that returns data for the year - tickers without data are free;
  • all or nothing: without enough tokens for the whole request the answer is 402 and nothing is charged;
  • tokens never expire; top up a key on the purchase page - the key stays the same.

Errors

Errors are JSON: {"error": "...", "status": 4xx, ...}

StatusMeaning
400a parameter is wrong - the message says which
401no key, an unknown or revoked key, or a disabled account
402not enough tokens - nothing was charged (tokens_required, tokens_remaining, buy_tokens)
404unknown data set
405method not allowed (the API is GET only)
503the data is temporarily unavailable

Examples

curl

curl "{{ api }}/catalog"
curl -H "Authorization: Bearer $STOCK_API_KEY" "{{ api }}/daily?ticker=MRK,PFE&year={{ sample_year }}"
curl -H "Authorization: Bearer $STOCK_API_KEY" -o monthly.csv "{{ api }}/monthly?ticker=JNJ&year={{ sample_year }}&format=csv"
curl -H "Authorization: Bearer $STOCK_API_KEY" "{{ api }}/balance"

Python

import json, os, urllib.request

req = urllib.request.Request("{{ api }}/weekly?ticker=HD&year={{ sample_year }}",
                             headers={"Authorization": "Bearer " + os.environ["STOCK_API_KEY"]})
with urllib.request.urlopen(req) as resp:
    answer = json.load(resp)
for row in answer["records"]:
    print(row["week_start"], row["close"])
print("tokens left:", answer["tokens_remaining"])

Keep the key out of your source code - read it from an environment variable as above.
