How it works

Buy a token pack

As a guest with just an e-mail address, or with an account. Pay by card (Stripe) or PayPal.

Get your API key

The receipt shows the key (sdl_…) once - copy it. Top it up any time; the key stays the same.

Call the API

Ask for up to {{ settings.max_tickers_per_request }} tickers per request. Tickers without data are free.

A request

curl -H "Authorization: Bearer <your key>" \
     "{{ base_url() }}/api/v1/daily?ticker=MRK,PFE&year={{ sample_year }}"

The answer lists the rows per trading day and what it cost - all endpoints and fields.
